# Pandas Data Preprocessing & Exploratory Analysis

This project demonstrates a complete data preprocessing and exploratory analysis workflow using Python and Pandas.

## Topics Covered

- DataFrame inspection
- Missing value treatment
- Duplicate removal
- Exploratory data analysis
- Data visualization
- One-Hot Encoding
- Ordinal Encoding
- StandardScaler
- MinMaxScaler
- IQR outlier detection and removal
- Final preprocessing for machine learning

## Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The dataset contains employee information including age, department, education level, experience, salary, performance score, and monthly working hours.

## Project Workflow

1. Inspected the dataset structure and data types.
2. Identified and treated missing values.
3. Removed duplicate records.
4. Performed exploratory data analysis and visualization.
5. Encoded categorical variables.
6. Applied feature scaling using StandardScaler and MinMaxScaler.
7. Detected and removed outliers using the IQR method.
8. Prepared a final cleaned dataset for machine-learning use.

## Key Findings

- Missing categorical and numerical values were treated appropriately.
- Duplicate records were identified and removed.
- Extreme outliers were detected in salary, age, and monthly working hours.
- Categorical variables were encoded for machine-learning use.
- Numerical features were transformed using StandardScaler and MinMaxScaler.
- Outlier removal noticeably improved the distribution of several numerical variables.

## Outcome

The final dataset contains cleaned, encoded, and scaled features and is ready for further machine-learning analysis.
