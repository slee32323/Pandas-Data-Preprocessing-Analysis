# Pandas Data Preprocessing & Exploratory Analysis

This project demonstrates a complete data preprocessing and exploratory analysis workflow using Python and Pandas.

## Topics Covered

- DataFrame inspection
- Missing value treatment
- Duplicate removal
- Exploratory data analysis
- Data visualization
- One-Hot Encoding
- Ordinal Encoding
- StandardScaler
- MinMaxScaler
- IQR outlier detection and removal
- Final preprocessing for machine learning

## Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The dataset contains employee information including age, department, education level, experience, salary, performance score, and monthly working hours.

## Key Findings

- Missing categorical and numerical values were treated appropriately.
- Duplicate records were identified and removed.
- Extreme outliers were detected in salary, age, and monthly working hours.
- Categorical variables were encoded for machine-learning use.
- Numerical features were transformed using StandardScaler and MinMaxScaler.
